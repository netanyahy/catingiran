# Инструкция по настройке catingiran (`cti`)

**catingiran** (`cti`) — быстрая терминальная IDE / редактор кода на чистом C в стиле Vim/OnVim с боковой панелью проводника файлов как в VS Code, вкладками сверху, подсветкой синтаксиса (**C/C++**, **Python**, **Java**, JS/TS, Shell/Conf), встроенным **менеджером плагинов**, сплитами, встроенным запуском кода, поиском по проекту и Git-интеграцией.

---

## 1. Установка и удаление

```sh
git clone https://github.com/netanyahy/catingiran.git
cd catingiran
make
sudo make install
```

После установки:
* Бинарник доступен как `cti` и `catingiran`.
* Готовый конфиг автоматически создаётся в `~/.config/catingiran/catingiran.conf`.
* Папка плагинов создаётся в `~/.config/catingiran/plugins/`.

Для полного удаления из системы:
```sh
sudo make uninstall
```

---

## 2. Настройка через `catingiran.conf`

Редактировать свой конфиг можно прямо внутри редактора командой **`:conf`**:
```text
~/.config/catingiran/catingiran.conf
```
После правок примените настройки без перезапуска командой **`:reload`**.

### Параметры `catingiran.conf`

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| `theme` | `charcoal` | Цветовая тема: `charcoal`, `obsidian`, `catppuccin`, `tokyonight`, `nord`, `light` |
| `tab_size` | `4` | Ширина табуляции (`1`–`16`) |
| `expand_tab` | `true` | Вставлять пробелы вместо `\t` |
| `line_numbers` | `true` | Показывать номера строк слева |
| `cursorline` | `true` | Подсвечивать текущую строку |
| `auto_indent` | `true` | Автоотступ при переносе строки |
| `auto_pairs` | `true` | Автозакрытие `()`, `[]`, `{}`, `""`, `''` |
| `show_tabs` | `true` | Верхняя панель вкладок открытых файлов |
| `mouse` | `true` | Поддержка мыши и колёсика скролла |
| `sidebar_open` | `true` | Открывать проводник файлов при старте |
| `sidebar_width` | `28` | Ширина боковой панели (`16`–`60`) |
| `show_hidden` | `true` | Показывать скрытые файлы в проводнике |
| `nerd_icons` | `true` | Иконки Nerd Font в дереве (`false` — чистые ASCII/Unicode символы) |
| `output_height` | `8` | Высота нижней панели вывода при запуске кода (`4`–`30`) |
| `git_branch` | `true` | Показывать текущую Git-ветку в статусной строке |
| `russian_keymap` | `true` | Поддержка русской раскладки в Normal/Command режиме (`ж` -> `:`, `р/о/л/д` -> `h/j/k/l`) |
| `plugin` | — | Подключение плагина: `plugin = user/repo` (можно несколько строк) |

## 3. Встроенный менеджер плагинов (`catingiran Plug`)

В `catingiran.conf` можно добавлять плагины:
```ini
plugin = user/repo
```
Или добавить прямо из редактора командой `:PlugAdd user/repo`.

Команды менеджера плагинов:
* `:PlugStatus` — открыть вкладку `[Plugins]` со списком настроенных и установленных плагинов.
* `:PlugInstall` — клонировать все плагины из `catingiran.conf` в `~/.config/catingiran/plugins/`.
* `:PlugUpdate` — обновить все установленные плагины (`git pull`).
* `:PlugClean` — удалить плагины, убранные из `catingiran.conf`.
* `:PlugAdd user/repo` — добавить строку `plugin = ...` в конфиг и сразу установить плагин.

Плагины могут содержать файл `plugin.conf` с пользовательскими командами (`command.mycmd = ...`) или темой (`theme = obsidian`).

## 4. Командная строка (`:` в стиле Vim / OnVim)

* `:conf` / `:reload` — открыть конфиг / перечитать конфиг и плагины.
* `:w` / `:w файл` / `:q` / `:q!` / `:wq` / `:x` — сохранить / выйти.
* `:e файл` / `:new` / `:bd` — открыть файл / новая вкладка / закрыть вкладку.
* `:t1` .. `:t9` *(или `:е1` .. `:е9`)* — переключение вкладок 1–9.
* `:ot` / `:ht` / `:tree` *(или `:от` / `:нт`)* — открыть / скрыть / переключить проводник файлов.
* `:vsplit` / `:split` / `:only` — вертикальный / горизонтальный сплит экрана / закрыть сплит.
* `:run` — скомпилировать и запустить текущий файл (C, C++, Python, Java, Shell, Makefile).
* `:out` / `:ho` — показать / скрыть нижнюю панель вывода.
* `:term` — открыть интерактивный терминал (`$SHELL`) прямо из редактора.
* `:find` — быстрый нечёткий поиск файлов по проекту.
* `:grep текст` — поиск текста по всем файлам проекта (`Enter` или `gf` на строке открывает файл на нужной строке).
* `:git` / `:diff` — статус/лог Git или текущий diff.
* `:stats` — статистика проекта (количество файлов по языкам, строки, размер, TODO/FIXME).
* `:theme <имя>` / `:themes` — смена темы на лету.
* `:mark` / `:dup` — закладка на строку / дублировать строку.
* `:help` — встроенная справка.

## 5. Горячие клавиши (`<Space>` = Leader)

* `Ctrl + B` / `F2` / `Space + e` — открыть/скрыть проводник файлов.
* `Ctrl + H` / `Ctrl + L` — фокус на проводник / редактор.
* `Ctrl + P` / `Space + ff` — быстрый поиск файлов по проекту.
* `Space + fg` — поиск текста по проекту (`grep`).
* `F5` / `Space + r` — запустить текущий файл.
* `Ctrl + J` — показать/скрыть нижнюю панель вывода.
* `Space + t` — открыть интерактивный шелл (`$SHELL`).
* `Space + v` / `Space + s` / `Space + x` — сплит вертикальный / горизонтальный / закрыть.
* `Ctrl + W` — переключиться между сплитами.
* `gcc` (в Normal) / `gc` (в Visual) — закомментировать/раскомментировать (`//` или `#`).
* `J` / `K` (в Visual) — переместить выделенные строки вниз/вверх.
* `m` / `M` — поставить/снять закладку (`★`) / перейти к следующей закладке.
* `Tab` / `Shift + Tab` / `Space + 1..9` — переключение вкладок.
* `Space + p` / `Space + g` — открыть `[Plugins]` / `[Git Status]`.
* `Space + w` / `Space + q` / `Space + c` — сохранить / выйти / закрыть вкладку.
