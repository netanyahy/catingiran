# Инструкция по настройке catingiran (`cti`)

**catingiran** (`cti`) — быстрый терминальный редактор кода на чистом C в стиле Vim/OnVim с боковой панелью проводника файлов как в VS Code, вкладками сверху, подсветкой синтаксиса и полной настройкой через `catingiran.conf`.

---

## 1. Установка и удаление

```sh
git clone https://github.com/netanyahy/catingiran.git
cd catingiran
make
sudo make install
```

После установки доступны команды `cti` и `catingiran`.

Для полного удаления из системы:
```sh
sudo make uninstall
```

---

## 2. Где лежит конфигурация (`catingiran.conf`)

1. Системный пресет устанавливается в `/usr/local/etc/catingiran.conf` (или `/usr/local/share/catingiran/catingiran.conf`).
2. При первом запуске `cti` автоматически копирует готовый пресет в:
   ```text
   ~/.config/catingiran/catingiran.conf
   ```
3. Вы можете редактировать этот файл прямо в самом редакторе (`cti ~/.config/catingiran/catingiran.conf`) и применять изменения без перезапуска командой `:reload`.

---

## 3. Все параметры `catingiran.conf`

| Параметр | Значение по умолчанию | Описание |
| --- | --- | --- |
| `theme` | `charcoal` | Цветовая тема: `charcoal`, `obsidian`, `catppuccin`, `tokyonight`, `nord`, `light` |
| `tab_size` | `4` | Ширина табуляции (от `1` до `16`) |
| `expand_tab` | `true` | Вставлять пробелы вместо символа `\t` |
| `line_numbers` | `true` | Показывать номера строк слева |
| `cursorline` | `true` | Подсвечивать текущую строку под курсором |
| `auto_indent` | `true` | Автоматический отступ при переносе строки |
| `auto_pairs` | `true` | Автозакрытие скобок и кавычек `()`, `[]`, `{}`, `""`, `''` |
| `show_tabs` | `true` | Показывать верхнюю панель вкладок открытых файлов |
| `mouse` | `true` | Поддержка мыши (клики по файлам, вкладкам, тексту, скролл) |
| `sidebar_open` | `true` | Открывать боковую панель проводника при старте |
| `sidebar_width` | `28` | Ширина боковой панели файлов (от `16` до `60`) |
| `show_hidden` | `true` | Показывать скрытые файлы (начинающиеся с `.`) в проводнике |
| `nerd_icons` | `true` | Иконки Nerd Font в дереве файлов (`false` — чистые ASCII/Unicode символы) |
| `russian_keymap` | `true` | Поддержка русской раскладки в Normal/Command режиме (`ж` как `:`, `р/о/л/д` как `h/j/k/l`) |

## 4. Командная строка (`:` в стиле Vim / OnVim)

* `:w` / `:w файл` — сохранить текущий файл (или сохранить как).
* `:q` / `:q!` — выйти (или выйти принудительно без сохранения).
* `:wq` / `:x` — сохранить и выйти.
* `:e файл` — открыть файл в новой вкладке.
* `:new` — создать пустую вкладку.
* `:bd` / `:c` — закрыть текущую вкладку.
* `:t1` .. `:t9` *(или `:е1` .. `:е9`)* — переключиться на вкладку 1–9.
* `:ot` *(или `:от`)* — открыть боковую панель файлов и перенести туда фокус.
* `:ht` *(или `:нт`)* — скрыть боковую панель файлов.
* `:tree` — переключить (показать/скрыть) боковую панель.
* `:theme <имя>` — сменить тему на лету (`:themes` покажет список).
* `:set number` / `:set nonumber` — включить/выключить номера строк.
* `:set icons` / `:set noicons` — включить/выключить иконки Nerd Font.
* `:set tabstop=2` — изменить ширину табуляции на лету.
* `:reload` — перечитать конфиг `catingiran.conf`.
* `:help` — открыть встроенную справку.

## 5. Горячие клавиши

### Редактор (Normal mode)
* `h / j / k / l` или стрелки — перемещение курсора.
* `w / b` — на слово вперёд / назад.
* `0 / $` — в начало / конец строки.
* `gg / G` — в начало / конец файла.
* `i / a / o / O` — вход в режим вставки (`Insert`), `Esc` — выход в `Normal`.
* `v` — режим выделения (`Visual`): `y` (скопировать), `d` (удалить), `>` / `<` (сдвиг отступа).
* `dd / yy / p / u` — удалить строку / скопировать строку / вставить / отмена (`Undo`).
* `/текст` — поиск (`n` — следующее совпадение, `N` — предыдущее).
* `Ctrl + B` или `F2` или `Пробел + e` — открыть/скрыть панель файлов.
* `Ctrl + H` / `Ctrl + L` — переключить фокус между панелью файлов и редактором.
* `Tab` / `Shift + Tab` или `Пробел + 1..9` — переключение вкладок.
* `Пробел + w` / `Пробел + q` / `Пробел + c` — сохранить / выйти / закрыть вкладку.

### Проводник файлов (когда фокус в боковой панели)
* `j / k` или стрелки — навигация по дереву.
* `Enter` или `l` — открыть файл во вкладке или развернуть папку.
* `h` или `Backspace` — свернуть папку или перейти к родительской папке.
* `a` — создать новый файл (добавьте `/` в конце имени для создания папки).
* `r` — переименовать выбранный файл/папку.
* `d` — удалить файл или пустую папку (с подтверждением `y/n`).
* `H` — показать/скрыть скрытые файлы.
* `R` — обновить дерево файлов.
