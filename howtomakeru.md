# Подробное руководство по catingiran (`cti`) v1.0.0

**catingiran** (`cti`) — полнофункциональная терминальная IDE и редактор кода на чистом C11 с архитектурой без внешних C-библиотек, Vim-грамматикой команд, асинхронным LSP-клиентом, проводником файлов в стиле VS Code, вкладками, сплитами и встроенным менеджером плагинов.

---

## 1. Установка, обновление и удаление

```sh
git clone https://github.com/netanyahy/catingiran.git
cd catingiran
make
sudo make install   # или: doas make install
```

После `make install`:
* Бинарник устанавливается в `/usr/local/bin/cti` (и симлинк `/usr/local/bin/catingiran`).
* Шаблон конфига копируется в `/usr/local/etc/catingiran.conf` и автоматически разворачивается в `~/.config/catingiran/catingiran.conf` при запуске или установке.
* Плагины хранятся в `~/.config/catingiran/plugins/`.

Полное удаление из системы:
```sh
sudo make uninstall
```

## 2. Настройка через `~/.config/catingiran/catingiran.conf`

Откройте конфиг прямо внутри редактора командой **`:conf`**. После изменений примените настройки на лету командой **`:reload`**.

### Внешний вид и темы

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| `theme` | `charcoal` | Тема оформления: `charcoal`, `obsidian`, `transparent` (`onvim`), `catppuccin`, `tokyonight`, `nord`, `light` |
| `show_tabs` | `true` | Показывать верхнюю строку открытых вкладок |

| `line_numbers` | `true` | Показывать номера строк в левом поле |

| `nerd_icons` | `true` | Иконки Nerd Font в дереве файлов (`false` — чистые ASCII/Unicode символы) |

## 3. Асинхронный LSP (Python, C/C++, Java)

При открытии файлов IDE автоматически запускает фоновый LSP-сервер, если он установлен в `$PATH`:
* **C / C++**: `clangd`
* **Python**: `pyright-langserver --stdio` (или `pylsp`)
* **Java**: `jdtls`

Возможности LSP:
* Ошибки и предупреждения подгружаются асинхронно и отмечаются в поле нумерации (`●` / `▲`), а текст ошибки показывается в нижней строке при наведении курсора на строку.
* `gd` — перейти к определению символа (`textDocument/definition`).
* `gr` — найти все ссылки на символ в буфере/проекте (`textDocument/references`).
* `K` — открыть всплывающую карточку документации (`textDocument/hover`), закрывается по `Esc` или любой клавише.
* `Space + r n` — переименовать символ по всему файлу/проекту (`textDocument/rename`).
* `:lsp` — открыть сводку запущенных LSP-серверов, PID и статуса.

## 4. Менеджер плагинов (`catingiran Plug`)

Команды для работы с плагинами:
* `:PlugList` — список встроенных языковых пакетов (`python`, `c`, `java`, `web`, `git-extras`).
* `:PlugAdd c` *(или `user/repo`)* — добавить плагин в `catingiran.conf` и сразу установить.
* `:PlugCreate myplug` — создать шаблон собственного плагина в `~/.config/catingiran/plugins/`.
* `:PlugStatus` — статус настроенных и установленных плагинов.
* `:PlugInstall` / `:PlugUpdate` / `:PlugClean` — установить, обновить через Git или удалить лишние плагины.

## 5. Vim-операторы, текстовые объекты, макросы и замена

* **Счётчики**: `5dd`, `10j`, `3k`, `3w`, `4x`, `3p`, `5u`, `5Ctrl+R`, `15G` / `15gg`.
* **Текстовые объекты (`c` / `d` / `y` + `i` / `a` + объект)**:
  * `ciw`, `diw`, `yiw` — изменить / удалить / скопировать слово под курсором.
  * `di"`, `da"`, `di'`, `da'` — внутри или включая кавычки.
  * `di(`, `da(`, `di{`, `da{`, `di[`, `da[` — внутри или включая скобки (включая многострочные блоки `{ ... }`).
  * В режиме Visual: `vi(`, `vi{`, `vi"`, `viw` и затем `d` / `c` / `y`.
* **Макросы**:
  * `qa` — начать запись макроса в регистр `a` (`a`–`z`, в статусной строке отображается `[REC @a]`).
  * `q` в Normal-режиме — остановить запись.
  * `@a` *(или `5@a`, `@@`)* — воспроизвести макрос.
* **Поиск и замена**:
  * `:%s/foo/bar/g` — заменить по всему файлу.
  * `:s/foo/bar/g` — заменить в текущей строке.
* **Отмена / Возврат**: `u` и `Ctrl+R` (или `:redo`).

## 6. Командная строка (`:`) и горячие клавиши (`<Space>` = Leader)

* `:w [файл]`, `:q`, `:q!`, `:wq`, `:x`, `:e файл`, `:new`, `:bd`, `:bn`, `:bp`
* `:ot`, `:ht`, `:tree` / `Ctrl + B` / `F2` / `Space + e` — управление проводником файлов (`H` — скрытые файлы, `a` — создать, `r` — переименовать, `d` — удалить).
* `:vsplit`, `:split`, `:only` / `Ctrl + W` / `Space + v/s/x` — сплиты.
* `:run` / `F5` / `Space + rr` — скомпилировать и выполнить текущий файл; `Ctrl + J` (`:out`/`:ho`) — панель вывода.
* `:find` / `Ctrl + P` / `Space + ff` — быстрый поиск файлов; `:grep текст` / `Space + fg` — поиск по содержимому (`Enter` / `gf` для перехода).
* `:git`, `:diff`, `:stats`, `:term` (`$SHELL`), `:lint`, `:fmt`, `:ft <язык>`, `:set number|relativenumber|ignorecase|smartcase|colorcolumn=N|tabstop=N|lsp`.
* `Ctrl + Space` — принудительный вызов меню автодополнения (`Tab`/`S-Tab` навигация, `Enter` вставка).
* `gcc` / `gc` (Visual) — комментировать строку; `J` / `K` (Visual) — двигать строки вверх/вниз.
* `m` / `M` — закладка (`★`) / следующая закладка; `]d` / `[d` — переход между ошибками линтера/LSP.
